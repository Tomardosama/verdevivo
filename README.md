# TRush

TRush is a 3D first-person ecological restoration game built with Godot 4.7.

## First playable foundation

- First-person movement with mouse look, WASD and sprint.
- Click-to-collect trash with a limited carrying bag.
- Recycling station: stand nearby and press **E** to deposit.
- Money reward and HUD.
- Procedurally assembled forest clearing, trees and scattered waste.
- Modular player, trash and HUD scenes/scripts.

## Run

1. Install Godot 4.7 (or a compatible Godot 4.x release).
2. Clone or pull this repository.
3. Import the folder containing `project.godot` in Godot.
4. Press F5.

## Controls

- **W A S D**: move
- **Mouse**: look
- **Shift**: sprint
- **Left click**: collect the trash under the crosshair
- **E**: recycle the bag near the station
- **Esc**: release mouse; click to capture again

This foundation uses primitive meshes so the gameplay loop can be validated before final art, audio, biome content and advanced progression are added.
